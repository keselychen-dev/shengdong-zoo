# 声动动物园

🎤 面向1-3年级小学生的早读分组PK工具。声音越大，动物园越热闹！

## 是什么

「声动动物园」是一款专为低年级课堂和家庭早读设计的互动网页工具。两组学生同屏对抗，通过朗读声音驱动可爱动物生成——声音越大，动物越多，获胜机会越大。

把"被动朗读"变成"主动PK"，让早读课成为孩子们最期待的环节。

## 功能特色

- **分组PK对抗** — A组 vs B组同屏实时对决，投屏到大屏全班参与
- **12种手绘动物** — 全部用CSS绘制，Q版可爱风格，不使用emoji和图片
- **声音驱动** — 模拟分贝检测，声音超过阈值自动生成动物
- **自定义队名** — 支持修改队伍名称（如"老虎队 vs 狮子队"）
- **PK计时** — 支持1分钟/3分钟/5分钟/不限时，倒计时自动结束
- **朗读任务** — 可选填朗读内容，显示在页面顶部
- **胜利庆祝** — 获胜组弹出撒花动画
- **灵活配置** — 分贝阈值、生成速度、动物种类均可调节

## 使用场景

| 场景 | 说明 |
|------|------|
| 课堂晨读 | 老师投屏到大屏，全班分两组PK朗读 |
| 家庭早读 | 家长打开网页，孩子朗读课文 |
| 朗读训练 | 个人练习，通过动物数量获得即时反馈 |

## 快速开始

无需安装，浏览器直接打开 `index.html` 即可使用。

```bash
# 克隆项目
git clone https://github.com/keselychen-dev/shengdong-zoo.git

# 打开页面
open index.html
```

## 技术实现

- 纯前端单页应用，零依赖
- 原生 HTML + CSS + JavaScript
- 12种动物全部用 CSS 绘制，不依赖外部图片
- 响应式布局，适配桌面投屏和移动端
- 单文件架构，所有代码内联在 `index.html` 中
